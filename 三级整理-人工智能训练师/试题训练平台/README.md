# 人工智能训练师三级 - 试题训练平台

## 平台简介

这是一个纯前端运行的试题训练平台，无需服务器部署，双击 `index.html` 即可在浏览器中使用。支持代码填空练习、答案检查、知识点管理等功能，帮助考生系统复习人工智能训练师三级考试内容。

## 快速开始

### 1. 直接使用（推荐）

更新内联数据 node generate-data.js

将 `试题训练平台` 文件夹解压/复制到任意位置，**双击 `index.html`** 即可在浏览器中打开使用。

> 提示：建议使用 Chrome、Edge 等现代浏览器以获得最佳体验。

### 2. 通过本地服务器运行

如果需要开发调试，可以使用以下任一方式启动本地服务器：

#### 方式一：使用 Node.js（推荐）

```bash
cd 试题训练平台
node server.js
```

然后浏览器访问 `http://localhost:8080`（如果端口被占用，会自动尝试 8081、8082 等）

**也可以指定端口：**

```bash
node server.js 3000  # 使用端口 3000
```

**优点：**

- 跨平台兼容性好（Windows/Mac/Linux）
- 自动寻找可用端口，无需手动配置
- 支持自定义端口参数
- 友好的错误提示

#### 方式二：使用 Python

```bash
cd 试题训练平台
python -m http.server 8080
```

然后浏览器访问 `http://localhost:8080`

**注意：** 如果 Python 命令不可用，请使用方式一（Node.js）。

## 核心功能

### 1. 代码填空练习

- 左侧题目列表选择题目
- 中间区域为代码填空区，下划线处为输入框
- 输入框宽度会自动根据内容调整
- 支持上一题/下一题切换

### 2. 答案检查

- 点击「检查答案」按钮，系统会自动对比填空答案
- 正确答案显示绿色，错误显示红色
- 支持模糊匹配（忽略空格差异）
- 检查后可查看「完整代码」对比差异

### 3. 刷题进度统计

- 题目选择上方显示当前刷题轮次和进度
- 每道题全部答对后标记为「已完成」
- 20道题全部完成后可开启新一轮练习
- 刷题数据自动保存在浏览器 localStorage 中

### 4. 知识点面板

- 右侧知识点面板可按模块查看核心代码
- 支持折叠/展开分类
- **知识点支持自定义编辑：**
  - 添加/编辑/删除分类标题（黄色标题）
  - 添加/编辑/删除代码项及备注
  - 鼠标悬停显示操作按钮
  - 删除操作需二次确认
- 知识点数据自动保存到 localStorage

## 关键数据文件说明

### data/questions.json

**用途：** 存储 20 道代码填空题的完整数据

**数据结构：**

```json
[
  {
    "id": "1.1.1",
    "name": "题目名称",
    "fillInCode": "填空代码（下划线表示填空位置）",
    "fullCode": "完整参考答案代码"
  }
]
```

**注意事项：**

- `fillInCode` 中使用连续 7 个或以上下划线（`___________`）表示填空位置
- `fullCode` 为对应的完整代码，用于答案提取和对比
- 修改此文件后需**重新生成 `js/data.js`** 并刷新页面生效
- 用户的刷题进度保存在浏览器 localStorage 中，不受此文件影响

### data/knowledge.json

**用途：** 存储知识点面板中的分类和代码数据

**数据结构：**

```json
[
  {
    "id": "1.1",
    "title": "模块标题",
    "points": [
      {
        "category": "分类标题",
        "items": [{ "code": "代码内容", "note": "备注说明" }]
      }
    ]
  }
]
```

**注意事项：**

- 首次加载时会自动转换为新格式（`{code, note}` 对象）
- 修改此文件后需**重新生成 `js/data.js`** 并刷新页面生效
- 修改后的数据保存在 localStorage 中
- 如需重置为原始数据，可清除浏览器 localStorage 中的 `knowledgeData` 项

## 数据持久化说明

以下数据自动保存在浏览器 localStorage 中：

| localStorage 键名 | 说明                 |
| ----------------- | -------------------- |
| `userAnswers`     | 用户的填空答案       |
| `practiceStats`   | 刷题轮次和进度       |
| `knowledgeData`   | 自定义后的知识点数据 |

> 提示：如需清空所有数据重新开始，可在浏览器开发者工具中清除对应网站的 localStorage。

## 使用提示

1. **首次使用：** 打开页面后，左侧题目列表会自动加载，点击任意题目即可开始练习
2. **答案输入：** 在代码中的下划线填空处输入答案，输入框会自动调整宽度
3. **检查答案：** 完成所有填空后，点击「检查答案」按钮查看结果
4. **查看完整代码：** 点击「完整代码」按钮可查看参考答案
5. **知识点复习：** 点击右侧「知识点」按钮展开/收起知识点面板
6. **自定义知识点：** 在知识点面板中可以对分类和代码进行增删改操作
