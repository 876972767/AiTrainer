# 考试模拟系统设计文档

## 项目概述
纯前端样式展示项目，用于模拟考试平台界面。整体采用白蓝浅色调。

## 技术栈
- HTML5 + CSS3 + Vanilla JS (ES6+)
- Quill.js (CDN) - 富文本编辑器
- Prism.js (CDN) - Python 代码高亮

## 页面结构（单页应用）

### 1. 登录页面 (login-view)
- 账号输入框 (提示: 身份证号)
- 密码输入框 (提示: 后6位)
- 登录按钮 → 无校验 → 弹出诚信承诺书

### 2. 诚信承诺书弹框 (pledge-modal)
- 通用考生诚信承诺书正文
- "同意"按钮: 初始灰显，倒计时3秒后可点击
- 点击"同意" → 考试页面

### 3. 考试页面 (exam-view)
- 顶部: 考试标题 + 120分钟倒计时
- 中部: 4个模块卡片 (2×2网格)
  - 业务分析 (1题)
  - 智能训练 (2题)
  - 智能系统设计 (2题)
  - 培训与指导 (1题)
- 卡片信息: 图标 + 题目数量 + 进度百分比

### 4. 题目答题页面 (question-view)
- 顶部: 返回按钮 + 模块标题 + 倒计时
- 左侧: 题目列表 (可切换)
- 中间: 当前题目描述 (question)
  - 下方 todo 列表: questionTitle + 去答题按钮 + 完成状态(✅/⭕)

### 5. 答题页面 (answer-view)
- 顶部: 返回按钮 + 保存按钮 + 倒计时
- 左侧答题区:
  - code: 代码编辑器(Prism高亮) + 运行按钮 → Toast"运行成功"
  - text: 空白Quill富文本编辑器(带工具栏)
  - docx: Quill富文本编辑器(预填充content, 带工具栏)
- 右侧:
  - 上半: 题目题干
  - 下半: mock文件夹(固定假文件: Excel, CSV等，可点击复制路径)
- 保存按钮 → Toast"保存成功"

## 返回层级
答题页面 → 题目答题页面 → 考试页面(4个模块)
